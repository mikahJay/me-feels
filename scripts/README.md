# Scripts

Cross-platform scripts for setting up and running the me-feels development environment.

## Setup

### Windows (PowerShell)
```powershell
.\scripts\setup.ps1
```

### macOS / Linux (Bash)
```bash
chmod +x scripts/*.sh
./scripts/setup.sh
```

## Start

### Windows
```powershell
.\scripts\start.ps1
```

### macOS / Linux
```bash
./scripts/start.sh
```
